Errata Hub

サイトを開く ソースコード

技術書を読んでいて見つけた誤りや「こう書いた方が読みやすい」という気づきを、読者が投稿して共有できる公開サイトです。 投稿には誤りの箇所（ページ・行や版・刷）を添えられ、出版社からの回答・対応状況は管理者が記録して公開します。

不特定多数が投稿する公開 UGC を題材に、認証・認可・データ整合性・セキュリティといった 「実運用で効いてくる設計」を一通り自分で実装することを狙いとしました。実際に運用しています。

  • 認可はサーバー層に集約 — 操作ごとに DB の最新ロールを確認する関数を通ることを唯一の信頼境界とし、画面側のガードは補助に留める
  • PostgreSQL の RLS は「公開裏口を塞ぐロック」として使い、データ操作は信頼できるサーバー経由に限定
  • ISBN-10/13 を ISBN-13 に正規化して名寄せ、一意制約で重複登録を防止
  • 削除等は操作前データを監査ログに記録
  • 単体テスト・E2E テストを CI で実行（lint / typecheck / test / build）
