Errata Hub

サイトを開く ソースコード

技術書を読んでいて見つけた誤りや「こう書いた方が読みやすい」という気づきを、読者が投稿して共有できる公開サイトです。 投稿には誤りの箇所（ページ・行や版・刷）を添えられ、出版社からの回答・対応状況は管理者が記録して公開します。

不特定多数が投稿する公開 UGC を題材に、認証・認可・データ整合性・セキュリティといった 「実運用で効いてくる設計」を一通り自分で実装することを狙いとしました。実際に運用しています。

  • 認可はサーバー層に集約 — 操作ごとに DB の最新ロールを確認する関数を通ることを唯一の信頼境界とし、画面側のガードは補助に留める
  • PostgreSQL の RLS は「公開裏口を塞ぐロック」として使い、データ操作は信頼できるサーバー経由に限定
  • ISBN-10/13 を ISBN-13 に正規化して名寄せ、一意制約で重複登録を防止
  • 削除等は操作前データを監査ログに記録
  • 単体テスト・E2E テストを CI で実行（lint / typecheck / test / build）

Redux State Editor

リポジトリ非公開

Redux の state を DevTools パネルのフォームから直接編集できる Chrome 拡張（プロトタイプ）です。 Vuex devtools にある「state をその場で書き換えて画面の変化を見る」操作を Redux でもできるようにしました。 編集は専用のアクションとして store に dispatch されるため、React-Redux が通常どおり再描画され、公式の Redux DevTools の履歴・タイムトラベルとも整合します。

  • Redux Toolkit のアプリならアプリ側の変更ゼロで動作（DevTools 用フックに相乗りする方式）
  • state はポーリングではなく store.subscribe からの push で配信（100ms スロットル）。push が使えない場合のみポーリングにフォールバック
  • 公式 Redux DevTools 拡張との共存に対応（読み込み順に依存しない）
  • Chrome Extension (MV3)
  • JavaScript
  • Redux / Redux Toolkit
  • GitHub Actions

anti-street-harassment

ソースコード

路上で迷惑行為を受けた際に、録画と警告メッセージで身を守るための Web アプリです。 ボタンひとつで、警告文の画面表示・音声読み上げ・録画が同時に始まります。アプリのインストールは不要です。

  • 警告メッセージは SpeechSynthesis で読み上げ、繰り返し再生。読み上げのオン/オフを切り替え可能
  • 録画はブラウザ標準の getUserMedia / MediaRecorder のみで完結し、サーバーに送信しない（端末内に留め、必要な人だけがダウンロードして証拠として残す）
  • 緊急時のための 110番通報ボタン
  • カメラの許可拒否・未接続・他アプリが使用中を切り分けて、対処方法つきで表示
  • Next.js 16
  • React 19
  • TypeScript
  • Tailwind CSS v4
